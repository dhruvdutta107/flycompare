Offers & Deals

Tap Apply & Search to save a code — it is applied automatically on the payment step. Codes are checked by our server against your actual trip.

How offers work

  • One code per booking. Discounts are taken off the base fare or total as described on each card.
  • You can also type a code yourself in the Promo code box on the payment page.
  • If a code does not apply to your trip we tell you exactly why.
